## Chapter format

Every chapter should contain core concepts, a lifecycle/request-flow diagram where useful, compare-and-choose trade-offs, implementation examples, common pitfalls, interview questions, a quick-revision checklist and a practical exercise.

## Interview answer framework

1. Define the concept in one or two sentences.
2. Explain the internal working or lifecycle.
3. Give a concrete application example.
4. Compare alternatives and explain trade-offs.
5. Mention failure modes, security and observability where relevant.

Do not memorize isolated answers. Be able to draw the flow, explain why a design works and identify what changes at higher scale.
