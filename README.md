# Web Security & Full-Stack Engineering Interview Handbook

**How to use this handbook:** choose a module, start at its README and follow the chapters in order. Each topic should explain the idea first, use a small example and then introduce technical terms. See the [Simple-Word Glossary](resources/GLOSSARY.md) for quick explanations.

A sequential learning and revision handbook with two distinct modules.

## Choose your module

| Module | Purpose | Start |
|---|---|---|
| **1 · Attack & Web Security** | Understand attacks, root causes, impact, prevention and verification | [Start Module 1](Module-1-Attack-and-Web-Security/README.md) |
| **2 · Full-Stack & Interview Preparation** | Learn web engineering from fundamentals through system design and interview revision | [Start Module 2](Module-2-Full-Stack-and-Interview-Preparation/README.md) |

## Module 1 — Attack & Web Security

The primary security track. Follow **domain → attack family → attack type → variant → root cause → impact → mitigation → verification**.

Start with the [Module 1 reading path](Module-1-Attack-and-Web-Security/docs/MODULE-1-ATTACK-SECURITY-PATH.md), then use the [attack catalog](Module-1-Attack-and-Web-Security/docs/ATTACK-CATALOG.md) and [attack playbook template](Module-1-Attack-and-Web-Security/docs/ATTACK-PLAYBOOK-TEMPLATE.md).

## Module 2 — Full-Stack & Interview Preparation

Read the curriculum in order. It covers HTTP, JavaScript/TypeScript, Core Web Development, frontend, backend, databases, cloud/DevOps, system design and interview revision. Detailed JavaScript/TypeScript, browser and Node.js subjects live in their own topic folders.

Start with the [Module 2 learning path](Module-2-Full-Stack-and-Interview-Preparation/README.md).

## Documentation site

Install requirements from `requirements-docs.txt`, then run `python -m mkdocs serve`. Run `python -m mkdocs build --strict` before publishing.

Prefer primary sources: OWASP, MDN, W3C/IETF specifications, framework documentation and cloud-provider guidance. Videos supplement, but do not replace, primary references.
