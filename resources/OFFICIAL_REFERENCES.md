# Official Security References

Primary sources should take precedence over unsourced tutorials. Standards and recommendations evolve, so check publication dates and current versions.

- [OWASP Top 10](https://owasp.org/www-project-top-ten/)
- [OWASP Application Security Verification Standard (ASVS)](https://owasp.org/www-project-application-security-verification-standard/)
- [OWASP Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/)
- [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/)
- [OWASP API Security Project](https://owasp.org/www-project-api-security/)
- [PortSwigger Web Security Academy](https://portswigger.net/web-security)
- [MDN Web Security](https://developer.mozilla.org/en-US/docs/Web/Security)
- [MDN Content Security Policy](https://developer.mozilla.org/en-US/docs/Web/HTTP/CSP)
- [MDN CORS](https://developer.mozilla.org/en-US/docs/Web/HTTP/CORS)
- [IETF RFC Editor](https://www.rfc-editor.org/) — authoritative RFC publications
- [OAuth 2.0 Security Best Current Practice (RFC 9700)](https://www.rfc-editor.org/rfc/rfc9700)
- [OpenID Connect specifications](https://openid.net/developers/specs/)
- [Google web.dev security](https://web.dev/learn/)
- [Mozilla Observatory](https://observatory.mozilla.org/) — header assessment; results are not a full security audit
- [OWASP ZAP](https://www.zaproxy.org/) — open-source web application security testing
