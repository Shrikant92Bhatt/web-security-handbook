# Frontend System Design — Video and Learning Resources

These resources complement the handbook. A course introduction is not the same as a complete free lesson series; check the description and access requirements before assuming all course content is public.

## Namaste Frontend System Design

- [Namaste Frontend System Design — Fundamentals, LLD, HLD and interview questions (YouTube)](https://www.youtube.com/watch?v=RCZ8mvsKEu4) — course overview from Akshay Saini. The description lists networking, communication protocols, REST, GraphQL, gRPC, polling, WebSockets, SSE, WebRTC, security, performance, PWA, testing, accessibility, caching, and state management.
- [Launching Namaste Frontend System Design (YouTube)](https://www.youtube.com/watch?v=rc3JGT56kd4) — introduction by Chirag Goel.
- [Official course page](https://namastedev.com/learn/namaste-frontend-system-design) — current curriculum and course details.
- [NamasteDev course curriculum repository](https://github.com/namastedev/namaste-frontend-system-design) — topic folders and example materials.

## Recommended study sequence

1. Read the [Frontend System Design chapter](../13-frontend-system-design/README.md).
2. Watch the Namaste FSD overview and scan its curriculum.
3. Study one communication and one performance topic.
4. Practice one LLD prompt and one HLD prompt with a timed 40–50 minute design.
5. Explain assumptions, data flow, failure modes, security, accessibility, metrics, and trade-offs.
6. Verify implementation details with [MDN](https://developer.mozilla.org/en-US/docs/Web) and relevant standards.
