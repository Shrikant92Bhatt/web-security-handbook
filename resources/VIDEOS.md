# Videos and Guided Learning

Video availability and URLs can change; verify the destination before sharing or relying on a lesson. Prefer structured training with hands-on practice.

## Free, hands-on web security
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) — free lessons and intentionally vulnerable labs across XSS, SQL injection, access control, SSRF, and more.
- [OWASP Juice Shop](https://owasp.org/www-project-juice-shop/) — deliberately insecure training application with guided challenges.
- [OWASP WebGoat](https://owasp.org/www-project-webgoat/) — lessons and exercises for common application-security weaknesses.
- [OWASP Top 10](https://owasp.org/www-project-top-ten/) — orientation to major web application risk categories.

## Suggested viewing sequence
Start with the OWASP Top 10, then PortSwigger's relevant topic lesson, then implement a mitigation and test it in a local application. Treat videos as introductions and verify security-critical advice against official documentation.
