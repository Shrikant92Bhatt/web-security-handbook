# Safe Practice Labs

Use intentionally vulnerable applications designed for training, locally or in a controlled environment.

- [PortSwigger Web Security Academy](https://portswigger.net/web-security)
- [OWASP Juice Shop](https://owasp.org/www-project-juice-shop/)
- [OWASP WebGoat](https://owasp.org/www-project-webgoat/)

## Lab rules
1. Keep exercises local or within an explicitly authorized environment.
2. Never enter real credentials, customer data, or production secrets.
3. Read the exercise scope and stop if a target is not clearly in scope.
4. Record the root cause, business impact, fix, and regression test—not just the payload.
5. Do not treat a successful scan or challenge completion as proof of security.

## Lab write-up template
- Objective and scope
- Affected asset and trust boundary
- Preconditions and impact
- Root cause
- Mitigation
- Verification steps and regression test
- References
