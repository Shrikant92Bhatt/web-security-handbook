## Future expansion structure

As a subject grows, expand it under its domain rather than adding another numbered folder at the repository root:

- Web fundamentals → HTTP, DNS, TCP/UDP, TLS and browser lifecycle
- JavaScript and TypeScript → runtime, closures, event loop, promises and advanced types
- Frontend engineering → browser, React, Angular, testing, performance and micro-frontends
- Backend engineering → Node.js, Python, Java/.NET, APIs, realtime communication, queues and scaling
- Data engineering → SQL, NoSQL, indexing, transactions, caching and search
- Cloud and DevOps → AWS, Azure, GCP, containers, Kubernetes and CI/CD
- System design → fundamentals, distributed systems, HLD, LLD and real-world designs
- Interview preparation → topic-wise questions, coding exercises and day-before revision

Create a deeper folder when it contains multiple chapters or practical exercises. Keep small concepts in the parent chapter until they need independent space.
