# JavaScript and TypeScript — Deep Learning Path

[Module 2 home](../README.md) · [Core interview curriculum](../15-fullstack-interview/02-javascript-typescript.md)

This subject area takes TypeScript from the basics to the features used in large React, Angular and Node.js applications. Read the pages in order. Each page explains the idea first, then the TypeScript name, a small example, common mistakes and interview questions.

## Learning path

1. [TypeScript foundations](01-foundations.md) — what TypeScript does, compilation, primitive types, annotations, inference, enums and structural typing.
2. [Objects and collections](02-objects-and-collections.md) — arrays, tuples, object types, records, maps, sets, readonly data and index signatures.
3. [Functions and generics](03-functions-and-generics.md) — function types, optional/default/rest parameters, overloads, call and construct signatures, generics, constraints and `this`.
4. [Interfaces, aliases and classes](04-interfaces-aliases-and-classes.md) — interfaces, type aliases, composition, classes, abstract classes, inheritance, access modifiers and overrides.
5. [Narrowing and utility types](05-narrowing-and-utility-types.md) — unions, intersections, guards, assertions, `satisfies`, built-in utility types and safe API data.
6. [Advanced type building](06-advanced-type-building.md) — `keyof`, `typeof`, indexed access, conditional, mapped and template literal types, `infer`, and advanced utilities.
7. [Project setup and compiler](07-project-setup-modules-and-tooling.md) — tsconfig, strict options, modules, namespaces, declaration files, declaration merging, decorators, diagnostics, ts-node and tsx.

## How to study

- Type every example yourself and change the values to see which errors TypeScript catches.
- For every type, ask: what valid value does it allow, and what invalid value does it reject?
- Use `unknown` at untrusted boundaries and validate runtime data. A TypeScript type does not validate JSON received from an API.
- Learn the common features first. Advanced types are useful when they make an API safer or clearer, not simply because they are clever.
